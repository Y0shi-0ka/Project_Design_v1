# 健康のみち

地域のウォーキングコースを地図上で分かりやすく表示し、  
利用者の健康促進と地域への関心向上を支援する Android アプリです。

本プロジェクトは、大学のプロジェクトデザイン実践において開発したアプリで、  
地域のウォーキングコースを「見つけにくい」「続けにくい」という課題に対して、  
スマートフォン上でコース情報を直感的に確認できる体験を目指して制作しました。

---

## プロジェクト概要

「健康のみち」は、地域に存在するウォーキングコースをアプリ上で可視化し、  
利用者が自分に合ったコースを探しやすくすることを目的としたアプリです。
また、アプリとしての使いやすさを高めるために、  
画面遷移や設定情報の保持、ローカルデータ管理なども含めて実装しています。

---

## 開発背景

健康維持のためにウォーキングを始めたいと考えていても、

- 近くにどのようなウォーキングコースがあるのか分からない
- 紙資料やWebページでは位置関係が把握しづらい
- 自分に合ったコースを見つけるまでの手間が大きい
- 継続的に利用するための導線が弱い

といった課題があります。

そこで本アプリでは、地域のウォーキングコースをスマートフォン上で扱いやすくし、  
健康づくりのきっかけを増やすことと地域資源としてのウォーキングコースの活用を促すことを目的に開発しました。

---

## 想定ユーザー

- 健康のためにウォーキングを始めたい人
- 地域の散策コースを気軽に知りたい人
- 観光や外出のついでに歩けるコースを探したい人
- 地図を見ながら直感的にコースを選びたい人

---

## 主な機能

### 1. ウォーキングコースの表示
地域のウォーキングコースをアプリ上で確認できます。  
利用者が複数の候補からコースを選びやすいように、  
地図ベースでの閲覧を意識した設計になっています。

### 2. 地図表示
Google Maps を利用して、コースや位置情報を視覚的に確認できます。  
一覧だけでは分かりにくい位置関係を直感的に把握できることが特徴です。

### 3. 現在地の活用
位置情報機能を利用することで、ユーザーの現在地をもとに  
周辺コースの確認や移動の起点として活用できる構成になっています。

### 4. 画面遷移の整理
Navigation を用いて、複数画面間をスムーズに移動できるよう実装しています。  
アプリ全体の操作性を高め、機能追加にも対応しやすい構成を意識しました。

### 5. ローカルデータ管理
Room を利用し、アプリ内で扱うデータをローカルに保存・管理できる構成にしています。  
今後の機能拡張にもつなげやすい基盤として設計しています。

### 6. 設定情報の保持
DataStore を利用し、ユーザー設定などの軽量データを保持できるようにしています。  
継続利用しやすいアプリにするための基礎機能として導入しています。

## 使用技術

このプロジェクトでは、以下の技術を使用しています。  
リポジトリ内の Gradle 設定から、Kotlin 製の Android アプリであり、  
Jetpack Compose ベースで Google Maps・位置情報・Navigation・Room・DataStore を導入していることが確認できます。

- **Language**
  - Kotlin

- **Platform**
  - Android

- **UI**
  - Jetpack Compose
  - Material 3

- **Map / Location**
  - Google Maps SDK
  - Maps Compose
  - Google Play Services Location

- **Architecture / App components**
  - Navigation Compose

- **Local storage**
  - Room
  - DataStore

- **Image handling**
  - Coil

- **Build Tool**
  - Gradle (Kotlin DSL)
